# AGENTS.md

Wikipilot's agent and skill conventions live in [CLAUDE.md](CLAUDE.md). Read that file in full before performing any operation on this repository — it defines the wiki schema, the file ownership matrix, the citation discipline, the cross-page sweep contract, and the per-agent model assignments that every routine and subagent must respect.

This pointer file exists so that tools which look for `AGENTS.md` (Codex, OpenCode, etc.) find the same instructions Claude Code does.
