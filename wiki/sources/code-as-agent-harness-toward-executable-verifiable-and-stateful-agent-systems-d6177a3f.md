## Excerpts

> In emerging agentic systems, code is no longer only a target output but increasingly serves as an operational substrate for agent reasoning, acting, environment modeling, and execution-based verification. We introduce code as agent harness: a unified view that centers code as the basis for agent infrastructure.

> The survey organizes the research around three connected layers: first, the harness interface, where code connects agents to reasoning, action, and environment modeling; second, harness mechanisms including planning, memory, and tool use for long-horizon execution, together with feedback-driven control and optimization that make harness reliable and adaptive.
