## Excerpts

> Three new features for Claude Managed Agents were announced, including multi-agent orchestration for creating fleets of agents to solve complex tasks. The features also include "Outcomes" to set what success looks like so Claude can iterate and get it done, and "Dreaming" - where Claude can inspect its previous sessions and figure out what it missed and self-improve. The Dreaming feature allows running a task overnight which examines previous sessions and creates new memories - in one example it created a descent-playbook.md file. Multiagent orchestration and Outcomes are both available in public beta. API volume is up 17x year-on-year on the Anthropic platform.
