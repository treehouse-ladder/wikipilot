## Excerpts

> PR review is now in the Agents Window, plans can build in parallel, and you can pin skills as quick-action pills. The /multitask command is now available in the editor for running async subagents to parallelize your requests instead of adding them to the queue; it will break down larger tasks into smaller chunks for a fleet of async subagents to tackle simultaneously. Split PRs will use chat context to identify logical slices, default to independent PRs unless dependencies are required, create a backup snapshot, and propose a split plan for your approval.
