## Excerpts

> NVIDIA announced MCP integrations across major creative tools including Adobe, Blender, Unreal Engine, Houdini and Affinity, enabling AI agents to work inside production pipelines.

> Cosmos 3 Edge, a 4-billion-parameter open world model, is now available for edge deployment on Jetson and RTX hardware, small enough to run real-time control on edge hardware while still reasoning about what it sees.

> SideFX is bringing MCP support to Houdini 22 through its new APEX Script workflow, allowing AI assistants to help artists generate and refine code for procedural character rigs.
