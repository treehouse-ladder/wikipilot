## Excerpts

> OpenHands Agent Canvas is a Open Source AI coding platform. Start locally, connect your tools, and automate workflows.

> You can run OpenHands, Claude Code, Codex, Gemini, or any ACP-compatible agent across local, remote, and cloud backends.

> It runs locally on your machine by default, but can connect to multiple agent backends, e.g. running agents in Docker containers, on VMs, or within your company infrastructure.

> Agent Canvas is powered by the OpenHands Agent Server, a REST API for running multiple agents on a single machine. Each Agent Server runs on a single host/port; the Agent Canvas can connect to multiple Agent Servers and easily flip between them.
