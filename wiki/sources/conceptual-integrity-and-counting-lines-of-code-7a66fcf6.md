## Excerpts

> Before coding agents, a software engineer could produce a few hundred lines of production-ready code per day; 200 lines of working, debugged, production-level code is an incredibly good day.

> Conceptual integrity is a concept from The Mythical Man-Month: well-designed software has an integrity to it: there are no surprises in it, it covers exactly the right domain of things, everything fits together and makes sense.

> With coding agents it's very easy to keep adding new rooms because the cost is so much cheaper, and what you end up with is something where the conceptual integrity falls apart.
