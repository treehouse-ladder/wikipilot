## Excerpts

> Artificial Analysis Intelligence Index v5.0.2 is built from nine evaluations. Terminal-Bench 4.1 is included at 10% weighting and Terminal-Bench-Science 0.1 at 15% weighting.

> Version 5.0.2 replaced Terminal-Bench 4.0 with Terminal-Bench 4.1, keeping the same 66 tasks, scored with updated verifiers that improve reliability and resistance to reward hacking. Reward-hacked trials are scored as 0 under reward-hacking detection, and token counting was revised for agents that report reasoning within output tokens. All models were regraded.

> The v5 announcement lists Terminal-Bench 4.0 (10%) under coding, while the v5.0.2 page lists Terminal-Bench 4.1; the v5.0.2 page is the more recent source.
