## Excerpts

> CA2 (Code-Aware Agent) uses call stack information to learn effective testing strategies, receiving the current function call trace along with the game state to learn how to reach specific target functions. Prior work has explored reinforcement learning for game testing, but without leveraging internal code signals such as the call stack. The researchers instrument two types of environments: State-based and Image-based, with support for efficient call stack extraction. Through experimental evaluation, CA2 achieves consistent improvement over non-code aware baselines that do not leverage call stack information.
