## Excerpts

> Claude in Microsoft Foundry is generally available today. Claude Opus 4.8 and Claude Haiku 4.5 are available in the Messages API, with core capabilities like prompt caching and extended thinking to support use cases ranging from coding and agentic work to complex reasoning. Claude in Microsoft Foundry is Azure-native, working with your existing Azure identity, networking, and governance controls.

> Microsoft Foundry provides enterprise customers with access to Claude models within their existing Azure environment, enabling organizations to build and deploy AI applications with the data residency, compliance, and security controls that Azure provides.
