## Excerpts

> Claude Fable 5 (running in Claude Code for web) built an entire game based on a 2024 tweet about a game concept for a team of raccoons going on heists. Fable started with an index page, vendored a copy of Three.js, then wrote its own gen_textures.py script. The game was tested using Playwright to take screenshots of its own work, allowing it to visually review and iterate on the design.
