## Excerpts

> AutoUE addresses the challenge of automatically generating 3D games in commercial game engines by coordinating multiple agents through complex engine-related workflows for generating assets such as scenes, blueprints, and code.

> The multi-agent system covers model retrieval, scene generation, gameplay and interaction code synthesis, and automated game testing for evaluation.

> An automated play-testing pipeline generates and executes runtime test commands, enabling systematic evaluation of dynamic behaviors.
