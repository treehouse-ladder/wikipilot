## Excerpts

> The attacker injects malicious prompts into benign rule files to induce coding agents to replace legitimate dependencies with attacker-controlled packages. PackHallu refines those prompts using feedback from a locally run surrogate agent, so it does not require access to the victim agent. Evaluations across multiple benchmarks, LLMs, and agent frameworks show that PackHallu achieves high attack success rates and strong transferability across diverse models and agent combinations.
