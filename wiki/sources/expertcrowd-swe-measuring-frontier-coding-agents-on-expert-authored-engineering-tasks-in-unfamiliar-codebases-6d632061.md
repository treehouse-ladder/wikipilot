## Excerpts

> ExpertCrowd-SWE is a 100-task benchmark of expert-authored, multi-file software engineering tasks for evaluating autonomous coding agents in large, unfamiliar codebases. The tasks span 87 open-source projects and 11 languages; the median ticket is 148 words while the median reference solution changes 471 lines. The authors evaluate seven frontier models, five runs each (3,495 scored runs), in a single platform harness that gives each model its provider-native tool interface.
