## Excerpts

> DeepSeek-V4-Pro-0813 is the official release of DeepSeek-V4-Pro. Compared with the preview version, the GA version greatly enhances agent capabilities, with particularly significant performance improvements in production environments.

> DeepSeek-V4-Pro-0813 is a 1.57T parameter model with 48B active parameters per token. It is built on the DeepSeek-V4-Pro (Preview) model structure, with a DSpark speculative decoding module attached.

> The thinking modes of V4-Pro and V4-Flash now support three thinking effort levels: low / high / max, allowing users to flexibly choose based on task complexity.
