## Excerpts

> The term agent harness circulates widely in software engineering with generative AI, naming the layer that wraps a language model and turns it into a coding agent able to act on a repository.

> We propose a constitutive definition that states the necessary and sufficient conditions for a system to be an agent harness, operationalize it as an inclusion and exclusion test, and draw the boundary of the concept against an agent framework, an agent SDK, an IDE plugin, an eval harness, and an orchestrator.

> The definition is applied to six real harnesses (Claude Code, Codex CLI, Aider, Cline, OpenHands, and SWE-agent) and deliberate edge cases.

> A harness is a stateful program that wraps a language model and determines what context the model sees at each step.
