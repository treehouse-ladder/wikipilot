# NVIDIA Open Sources Audio2Face Animation Model

## Excerpts

> NVIDIA is open sourcing the Audio2Face models and SDK, as well as the Audio2Face training framework, so anyone can fine-tune and customize the pre-existing models for specific use cases.

> The SDK contains C++ and Python source code through the MIT license.

> The Audio2Face technology uses AI to generate realistic facial animations from audio input by analyzing acoustic features like phonemes and intonation, providing accurate lip-sync and emotional expressions.
