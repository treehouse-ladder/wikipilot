## Excerpts

> Our results show that dynamic concurrency benefits most on long-horizon tasks, while bounded tasks often see little or negative improvement. The study compares the native dynamic-concurrency mechanisms of three coding agents (Codex Multiagent Version 2, Claude Code Dynamic Workflow, and Kimi Code AgentSwarm) across 354 tasks and 2,124 executions (226 repository generation tasks, 28 sustained repository evolution tasks, and 100 bounded coding tasks from SWE-bench Verified), recording 11.2 billion tokens corresponding to $20,780.02 at standard API rates. Concurrency raised token consumption to roughly 1.4 to 3.3 times that of sequential runs. The authors analyze matched trajectories to identify 13 concurrency-specific failure modes and 28 observable patterns.
