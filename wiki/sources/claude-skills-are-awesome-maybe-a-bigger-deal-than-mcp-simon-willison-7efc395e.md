## Excerpts

> A skill is conceptually simple — a Markdown file telling the model how to do something, optionally accompanied by extra documents and pre-written scripts that the model can run.

> Claude Code is poorly named — it's not purely a coding tool but a tool for general computer automation. Anything you can achieve by typing commands into a computer can now be automated by Claude Code, making it a general agent.
