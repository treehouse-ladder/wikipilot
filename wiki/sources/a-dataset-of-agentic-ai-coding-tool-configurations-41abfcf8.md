## Excerpts

> This dataset covers agentic AI coding tools such as Claude Code and OpenAI Codex that execute multi-step coding tasks with limited human oversight.

> We collected 2,847 real-world configuration files from public GitHub repositories, covering CLAUDE.md files, .cursorrules files, Codex system prompt files, and equivalent tool-specific configuration artifacts.

> Analysis reveals that configurations cluster around five patterns: context-injection (project description + conventions), tool-restriction (allowlist/denylist for shell commands), persona-setting (role + tone), memory-scaffolding (chain-of-thought templates), and output-format (diff vs. prose vs. structured JSON).
