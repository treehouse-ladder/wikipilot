## Excerpts

> For long-horizon tasks evaluated across models with comparable frontier capability, the agent execution harness — namely the infrastructure layer that governs context construction, tool interaction, orchestration, and verification around a language model — is often a stronger determinant of agent performance than the model it wraps. We formalize and defend the Binding Constraint Thesis: performance variance is governed more by harness configuration than by model choice, and current evaluation protocols therefore systematically misattribute harness-level gains to model improvements.
