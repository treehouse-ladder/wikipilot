## Excerpts

> Claude Code on the web is now in beta as a research preview, allowing you to assign multiple coding tasks to Claude that run on Anthropic-managed cloud infrastructure, perfect for tackling bug backlogs, routine fixes, or parallel development work.

> Each session runs in its own isolated environment with real-time progress tracking, and you can actively steer Claude as it works.

> With Claude Code running in the cloud, you can run multiple tasks in parallel across different repositories from a single interface and ship faster with automatic PR creation and clear change summaries.

> As part of this research preview, Claude Code is also available on the iOS app so developers can explore coding with Claude on the go.

> Every Claude Code task runs in an isolated sandbox environment with network and filesystem restrictions, and Git interactions are handled through a secure proxy service that ensures Claude can only access authorized repositories.

> Claude Code on the web is available now in research preview for Pro and Max users at claude.com/code.
