## Excerpts

> Artificial Analysis has launched intelligence and inference benchmarking for models that fit on mobile phones. Mobile phone inference benchmarking is operated in partnership with Liquid AI, measuring speed, latency, and memory use on real phones in a standardized testing environment.

> Intelligence is measured by a set of five evaluations selected to represent the types of function/tool calling, knowledge and reasoning tasks small models are often asked to accomplish. Performance is measured on real devices using the same quantized builds used on mobile phones.

> Artificial Analysis has independently validated Liquid AI's inference benchmarking methodology, which includes a standardized testing harness and a climate-controlled physical testing facility for repeatable results.
