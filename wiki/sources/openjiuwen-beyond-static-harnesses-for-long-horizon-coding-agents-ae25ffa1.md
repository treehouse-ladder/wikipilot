> Long-horizon coding agents operate over evolving repository states while increasingly relying on heterogeneous capabilities, delegated agents, and multi-agent coordination. openJiuwen is an open-source harness designed for both developer composability and adaptive task execution. It addresses two challenges: developers need to compose capabilities, reconfigure execution logic, and scale increasingly complex agent systems without repeatedly rebuilding orchestration (Structural Composability), and complex coding tasks continuously produce new evidence — such as semantic diagnostics and execution outcomes — that should dynamically influence subsequent runtime decisions (Runtime Adaptivity). openJiuwen exceeds the strongest selected leaderboard results by 3.39 percentage points on Terminal-Bench 2.1 and by 3.4 percentage points on SWE-bench Verified.
