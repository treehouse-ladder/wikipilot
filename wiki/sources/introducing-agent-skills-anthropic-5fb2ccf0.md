> Agent Skills have been published as an open standard. We believe skills should be portable across tools and platforms — the same skill should work whether you're using Claude or other AI platforms.

> As of January 2026, individual users can upload skills to Claude.ai via Settings > Capabilities > Skills, or place them in the Claude Code skills directory. Organization-level skills can be deployed workspace-wide, with automatic updates and centralized management.
