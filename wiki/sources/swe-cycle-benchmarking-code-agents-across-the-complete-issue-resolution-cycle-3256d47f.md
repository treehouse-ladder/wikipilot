## Excerpts

> SWE-Cycle is the first benchmark evaluating agents across the complete issue resolution lifecycle. It was curated via a rigorous filtering pipeline to retain 489 high-quality instances, supporting both independent Isolated Task evaluation and a FullCycle setting.

> A major innovation of this work is the introduction of SWE-Judge, an evaluation methodology. Moving beyond the binary pass/fail metrics of predefined scripts, SWE-Judge employs task-specific validation protocols to accommodate diverse valid implementations, uncover structural defects, and capture fine-grained partial correctness.

> Even within Isolated Tasks, traditional deterministic script evaluation produces severe misjudgments and false signals, while SWE-Judge provides a reliable assessment protocol across all four SWE-Cycle tasks and is strongly validated against human annotations.
