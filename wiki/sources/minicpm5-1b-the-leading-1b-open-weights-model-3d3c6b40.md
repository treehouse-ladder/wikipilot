## Excerpts

> OpenBMB released MiniCPM5-1B (Non-reasoning) on May 26, 2026, establishing it as the leading 1B open weights model. MiniCPM5-1B scores 17.9 on the Artificial Analysis Intelligence Index, the highest of any open weights model at 1B parameters or below by 7.4 points.

> MiniCPM5-1B is a dense 1B parameter Transformer model built mainly for local deployment, edge AI, coding agents, and on-device assistants. It supports a 131K token context window inside a 1B parameter model.

> Compared with strong open-source models in the same size class, MiniCPM5-1B reaches SOTA within this comparison set, with advantage most visible in agentic tool use, code generation, and difficult reasoning.

> OpenBMB put its full MiniCPM5-1B stack in the open under Apache-2.0, including weights, the pre-training corpus, and deployment code.
