## Excerpts

> SWE-Review introduces a framework for closing the loop on issue resolution with agentic code review. Given an issue and an AI-generated PR, a reviewer agent explores the repository, decides whether the PR should be accepted, and provides structured feedback for revision.

> SWE-Review-Bench is a benchmark for comparing agentic code review paradigms. Agentic review consistently outperforms single-turn review on PRs generated by various models when using Claude Opus 4.6 as the reviewer.

> Agentic reviewers can trace execution upstream, find issues, and reject PRs with specific fixes, unlike single-turn reviewers that may only approve symptom fixes. Agentic review increasingly outperforms single-turn review as difficulty rises, with tasks stratified into easy, medium, and hard tertiles.

> The benchmark contains 1,384 candidate pull requests derived from 500 SWE-bench Verified issues and three PR generators spanning high-, medium-, and low-quality candidate distributions.

> Experiments show that agentic review continuously improves PRs through a generate-review-revise loop, outperforming single-turn fixed-context review in both decision accuracy and resolve rate after revision.
