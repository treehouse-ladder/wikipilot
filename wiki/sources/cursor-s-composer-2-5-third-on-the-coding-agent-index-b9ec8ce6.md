## Excerpts

> Composer 2.5 scored 62 on the Coding Agent Index, a 14 point gain over Composer 2 (48), putting it in third place behind only Claude Opus 4.7 (max) in Claude Code (66) and GPT-5.5 (xhigh reasoning) in Codex (65).

> Composer 2.5 improves on all benchmarks versus Composer 2, most notably on SWE-Bench Pro: +35 points on SWE-Bench-Pro-Hard-AA, +2 points on Terminal-Bench v2, and +3 points on SWE-Atlas-QnA. At 47%, Composer 2.5's score on SWE-Bench-Pro-Hard-AA is comparable to Claude Opus 4.7 (max) in Claude Code.

> Pricing is $0.50/$2.50 per million input/output tokens for the standard variant; $3.00/$15.00 for the Fast variant. Cursor with Composer 2.5 is the cheapest agent scoring above 60 on the Coding Agent Index at $0.07 (standard) and $0.44 (Fast) per task.

> These competitors cost $4.10 and $4.82 per task respectively, ~10x the cost of Composer 2.5 Fast ($0.44) and ~60x the cost of Composer 2.5 standard ($0.07).
