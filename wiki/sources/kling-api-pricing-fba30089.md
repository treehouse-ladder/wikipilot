> The Kling API pricing page lists Kling 4.0 as Coming Soon. Kling 4.0 API access is not yet available, and the prices are for preview purposes only and cannot be used to submit requests before launch.

> Preview API rates per second of output: without video input, 720p is listed at 1.0 unit/s and 1080p at 1.5 units/s. With video input, the rates drop to 0.6 and 0.9 units/s.
