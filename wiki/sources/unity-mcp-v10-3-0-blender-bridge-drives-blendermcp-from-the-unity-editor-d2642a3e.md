## Excerpts

> v10.3.0 introduces the Blender Bridge, which allows you to drive BlenderMCP from the Unity Editor through a tool and Asset Gen panel.

> The Asset Gen tab includes a Blender Bridge panel that features addon socket host/port configuration with Test Connection, blender-mcp checkout selection with validation, Blender addons folder detection with sync indicator, and Sync Addon / Check Updates / Import Selection buttons.

> Unity MCP acts as a bridge between AI assistants and your Unity Editor, giving your LLM tools to manage assets, control scenes, edit scripts, and automate tasks within Unity.

> The release also adds auto-discovery of live fal and OpenRouter asset models.
