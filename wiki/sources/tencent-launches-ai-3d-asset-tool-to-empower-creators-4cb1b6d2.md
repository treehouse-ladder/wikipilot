## Excerpts

> Tencent has launched the Hunyuan 3D engine globally, which aims to 'empower creators' with 'advanced' tools that allow users to make AI-generated 3D assets. The Hunyuan 3D tool allows users to generate assets with text, image, and sketch inputs.

> Tencent says doing so 'cuts production time from days or weeks to just minutes,' which helps to eliminate 'the complexity of traditional workflows.' The global launch encompasses Tencent Cloud making the Hunyuan 3D Model API available to enterprises across the globe.

> More than 150 enterprises in Mainland China have integrated the API through Tencent Cloud, including Unity China, Bambu Lab, and Liblib. Users can do up to 20 free generations daily, while enterprise users receive 200 free credits for generating assets.
