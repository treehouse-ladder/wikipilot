## Excerpts

> Mistral Large 4 (Le Chonk) is now open weight. The weights are available on Hugging Face under mistralai/Mistral-Large-4-1T-A52B, with an additional NVFP4 build for NVIDIA Blackwell GPUs.

> The model ships under the Mistral Ecosystem Open-Weight License, a modified MIT license. Use, modification, fine-tuning and commercial use are allowed. Businesses that operate a Model-as-a-Service offering must obtain a separate commercial license from Mistral before using the model commercially.

> API pricing: $0.70 per million input tokens, $0.07 per million cached input tokens, and $2.10 per million output tokens.

> Mistral Large 4 is a 1.05T total / 52B active parameter natively multimodal mixture-of-experts model with a 1.6B-parameter vision encoder and a 1M-token context window.
