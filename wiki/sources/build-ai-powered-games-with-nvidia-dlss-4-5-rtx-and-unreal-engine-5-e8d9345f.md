## Excerpts

> A new TensorRT for RTX plugin speeds up AI tasks in Unreal Engine's Neural Network Engine, making AI features in games run faster and smoother.

> NVIDIA Kimodo helps create realistic 3D human motion from simple inputs like text or keyframes, making animation easier and faster for developers.

> Instead of relying entirely on authored or captured animation clips, developers can generate motion data to prototype behaviors, create variations, or fill gaps between animations.

> NVIDIA released DLSS 4.5 with Dynamic Multi Frame Generation and a second-generation transformer model, improving game image quality and frame rates while keeping responsiveness.
