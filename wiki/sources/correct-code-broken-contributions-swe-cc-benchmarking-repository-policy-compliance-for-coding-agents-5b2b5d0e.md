## Excerpts

> Our semi-automated pipeline converts developer documentation across 12 open-source repositories into 823 machine-checkable atomic policies, each with a deterministic checker function, and audits both agent runtime behavior and final deliverables over 500 end-to-end contribution tasks adapted from SWE-bench Verified. Across four LLMs and two agent scaffolds, agents violated 43.1% of applicable policies, and nearly half of those violations happened during intermediate execution steps, not in the final output.
