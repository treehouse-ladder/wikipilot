## Excerpts

> Introducing SFX v3 in ElevenCreative and ElevenAPI. SFX v3 is now available to every workspace. In ElevenCreative, SFX v3 is the default model in Sound Effects, Studio and Flows.

> SFX v3 follows prompts with several instructions more closely than v2. List events in the order they should occur, for example footsteps followed by a door opening.

> The API model ID is eleven_text_to_sound_v3. Pricing is 40 credits per second when a duration is specified; duration ranges from 0.5 to 30 seconds, with prompt_influence defaulting to 0.3.

> The eleven_text_to_sound_v2 model is deprecated and will be removed on March 1, 2027. Its replacement is eleven_text_to_sound_v3.
