## Excerpts

> Underdog Woof is a small English text-to-speech model with two voices, Juno and Mira. It runs on a laptop CPU with nothing but numpy, from a single 40.6 MB file.

> Woof generates 24 kHz mono audio. Both voices are stored in the one weights file, and its audio decoder is adapted from Kyutai's Mimi codec. The model has 38.24M parameters total.

> Word error rate is 1.53% for Juno and 1.42% for Mira on Gradium TTS Hard Cases (English). Juno runs 13.8x faster than real time on one CPU thread; Mira runs at 7.2x real time. Peak memory is 402 MB for Juno and 601 MB for Mira.
