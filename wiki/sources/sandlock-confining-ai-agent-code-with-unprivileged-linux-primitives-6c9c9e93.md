## Excerpts

> AI agents increasingly run untrusted code on developer machines, including shell commands generated by language models, third-party scripts retrieved at runtime, and tool plugins of unknown provenance. Sandlock is a lightweight Linux process sandbox organized around a simple split: static, input-independent policy is compiled into kernel-enforced rules (Landlock and seccomp-bpf), while a narrow seccomp-notification supervisor handles runtime-dependent decisions and virtualized effects — readable path prefixes, writable workspaces, TCP ports, IPC scope, and unconditional syscall denials stay in kernel-enforced rules, while policies that depend on runtime values such as the resolved destination of a connect, the argv of an execve, an HTTP method/path, or a copy-on-write filesystem effect require controlled supervisor involvement.
