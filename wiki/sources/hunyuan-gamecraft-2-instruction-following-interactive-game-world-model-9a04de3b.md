> Instead of relying on fixed keyboard inputs, the model allows users to control game video contents through natural language prompts, keyboard, or mouse signals, enabling flexible and semantically rich interaction within generated worlds. The model leverages a 14B-parameter MoE diffusion backbone with innovations like self-forcing distillation, sink tokens, and block-sparse attention for efficient real-time synthesis.
