## Excerpts

> GameXpert-Bench operationalizes three lifecycle stages of game development as complementary benchmark tracks: initial game generation, bug diagnosis and repair, and optimization over multiple turns.

> GameGen asks an agent to create a complete game from a single request in an empty workspace, without supplied assets or a prescribed engine, containing 97 tasks across 11 genres, including 44 3D games.

> GameFix presents agents with partially-implemented games containing deliberate bugs spanning logic errors, physics issues, and rendering artifacts, requiring diagnosis and repair without breaking existing functionality.

> GameOpt runs multi-turn optimization sessions where an agent must iteratively improve an existing game — adding features, improving performance, enhancing feel — measured against expert-authored rubrics.

> Current state-of-the-art coding agents achieve expert-level performance on only 23% of GameGen tasks, 31% of GameFix tasks, and 18% of GameOpt tasks, revealing substantial gaps in holistic game development competence.
