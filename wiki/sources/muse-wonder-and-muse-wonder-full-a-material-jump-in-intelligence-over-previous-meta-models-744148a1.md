## Excerpts

> Muse Wonder and Muse Wonder Full score 52 and 56 at max reasoning effort on the Artificial Analysis Intelligence Index v4.3, above Muse Spark 1.3 (max), which scored 48.

> The largest gains were seen in agentic evaluations, including Terminal-Bench 4.0 rising from 33% to 57%.

> Muse Wonder Full's gain in intelligence comes in large part from lowering its hallucination rate from 33% to 23%. Muse Wonder Full also uses 16% fewer input tokens per Intelligence Index task than Muse Wonder (max), but its Intelligence Index run generated 140M tokens, verbose relative to the median of 88M.

> Muse Wonder is available on Meta's first-party API and in Muse Code at $4.00 per 1M input tokens and $20.00 per 1M output tokens, with cached input at $0.20 per 1M tokens and a 1M-token context window. Muse Wonder Full is available only to Muse Code users and is not priced per token, so no Cost per Task figure is available.
