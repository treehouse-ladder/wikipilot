## Excerpts

> Grok V9-Medium has completed training at 1.5 trillion parameters - three times the current production model - with a public release expected in mid-June 2026.

> V9-Medium runs on 1.5 trillion parameters - three times the size of the 500-billion-parameter v8-small model currently powering Grok in production, and was also trained on Cursor data, meaning real developer workflows from one of the most widely used AI code editors, rather than solely on public code repositories.

> Claude Opus 4.7 currently leads SWE-bench Verified at 87.6% versus Grok 4 at ~75%; the V9-Medium release will test whether the parameter increase plus Cursor data closes that gap.
