## Excerpts

> Starting November 1, 2026, 00:00 UTC+8 (October 31, 2026, 16:00 UTC): Tripo API V2 will be officially retired. All V2 API endpoints will stop accepting requests.

> Starting December 1, 2026, the Tripo API will switch to displaying feature prices and account balances in USD, at a rate of 1 credit = $0.01.

> v3.0 is priced by output topology: 35 credits for a triangle mesh, and 40 credits for a quad mesh (quad=true). v2.0 stays at 30 credits and v1.0 is unchanged.

> The base URL moved to https://openapi.tripo3d.ai/v3/, and V3 uses dedicated endpoints per task type with a unified input field instead of a type field.
