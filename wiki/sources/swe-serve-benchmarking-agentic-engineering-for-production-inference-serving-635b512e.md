## Excerpts

> SWE-Serve provides 53 repository-grounded tasks derived from recent production changes to SGLang, spanning six inference engineering families.

> Each task executes on either CPU or a single GPU (H100) and is evaluated with hidden functional and regression tests, including, where applicable, end-to-end (E2E) serving tests.

> SWE-Serve provides an executable, production-grounded evaluation of whether agents carry locally working implementations through a complete production path.
