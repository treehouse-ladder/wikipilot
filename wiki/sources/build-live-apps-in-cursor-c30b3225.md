## Excerpts

> Start a cloud agent and ask it to build an app. Cursor will scaffold the web app, spin up a Postgres database if needed, set up authentication behind Cursor SSO, and provision hosting. If the app needs outside systems, such as a data warehouse, Cursor will ask for the secrets it needs.

> When you go to publish your app, you pick a unique domain and Cursor gets you back a live link. Cursor can deploy apps from new or existing repos across Cursor Origin and GitHub, with GitLab support planned.

> On publish, Cursor will run deterministic and agentic security checks to catch common issues, like secrets written in app files or exposed credentials. Nothing goes live until the checks pass and you explicitly publish the app.

> Team admins can see every app and secret on the team. They can also add their own review rules, approve publishes that were blocked, and unpublish any app.

> This capability is now available on all paid plans with cloud agents enabled.

> The Origin App Marketplace now integrates with over 20 apps for deployments, CI, code review, security, monitoring, and project management, with partners including Cloudflare, Linear, Sentry, and Socket Security. The marketplace is also open to public submissions.
