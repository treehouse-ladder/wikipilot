## Excerpts

> GitHub is replacing PRUs (Premium Request Units) with a new unit called GitHub AI Credits, which are based on the tokens your interactions consume and priced according to the listed API rates per model. 1 AI credit = $0.01 USD. Copilot Pro+ includes $70 worth of AI Credits per month. Community feedback sharply negative: single prompts reportedly consuming '$4.51,' with some Pro+ users exhausting monthly allocations in 'one afternoon.'
