## Excerpts

> Origin is Cursor's git forge for storing and sharing code. Use it to host repositories, sync projects from GitHub, and browse your team's Origin repos in the browser. Origin begins rolling out today in early beta on all paid plans.

> Origin works with Cursor Automations and cloud agents so agents can review, change, and push code on your Origin repos.

> Your code, PRs, and agents are now in the same place. Ask Cursor questions about code you're browsing. It can answer, make changes, update PRs, or push a branch.

> Pull requests on synced repos sync both ways: comment in Cursor and it posts to GitHub, react or reply on GitHub and it shows up in Cursor within seconds.
