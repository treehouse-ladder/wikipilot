## Excerpts

> Procedural 3D modeling through code is emerging as a versatile paradigm, offering deterministic, engine-ready, and precisely editable assets that neural 3D generators inherently lack.

> 3DCodeBench evaluates how effectively 12 advanced VLMs can serve as procedural 3D modelers by translating text and image references into procedural code for 3D modeling software.

> Failures mostly arise from API mismatches, while successful renders still suffer from disconnected or floating 3D geometric components.

> Test-time scaling, such as higher thinking budgets and multi-turn refinement, improves performance overall.
