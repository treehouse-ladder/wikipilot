> Added sandbox.allowNestedUserNamespaces so sandboxed commands on Linux can create user namespaces (Chromium, rootless podman); this also weakens the sandbox's file protections. Fixed a 2.1.304 regression where requests failed on Vertex, Bedrock and other providers whose gateway rejected tool search; Claude Code now retries without it.
