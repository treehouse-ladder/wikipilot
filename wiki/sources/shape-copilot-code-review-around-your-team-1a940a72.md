## Excerpts

> Today we're shipping two public previews of Copilot code review: Agent skills and MCP support that bring your organization's context into every review, plus a new medium analysis tier that routes complex pull requests to a higher-reasoning model.

> Custom agent skills invoke your team's internal tools and standards during a review, extending Copilot beyond its built-in analysis. To set up agent skills for code review, create a .github/skills directory with a code-review or similarly named subdirectory, and create a SKILL.md file containing the relevant context and instructions you want Copilot code review to utilize.

> MCP server connections pull context directly into the review from third-party platforms and internal systems your team already uses, including issue tracking and documentation. The new Medium tier routes pull requests to a higher-reasoning model purpose-built for deeper analysis of complex logic, security-sensitive code, and cross-service changes.
