## Excerpts

> GLM-5.3 is the most capable open-weights model for coding, with a 50% improvement over GLM-5.2 on Z.ai's in-house Code Bench, and the model has been released on Hugging Face.

> GLM-5.3 achieves open-source SOTA on public benchmarks including Terminal Bench 3.0 and Agents' Last Exam.

> GLM-5.3 is state of the art on CyberGym for vulnerability discovery, and its gains are largest further up the exploitation chain, where it more than doubles GLM-5.2 on exploitation benchmarks.

> GLM-5.3 was evaluated in Claude Code 2.1.207 with max reasoning effort, no web tools, using temperature=1.0, top_p=1.0, and max_new_tokens=128000, with all evaluations under unlimited timeout per task and results as single-run Pass@1 over 1,507 tasks.

> GLM-5.3 is released by Z.ai (zai-org) under the MIT license.
