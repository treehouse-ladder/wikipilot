## Excerpts

> the first systematic empirical study and benchmark of open- and closed-source coding agent harnesses. Their benchmark has 23 tasks across five attack surfaces, and it tests nine mechanisms across six harnesses: Claude Code, Codex CLI, Gemini CLI, gptme, Qwen Code, and GitHub Copilot.

> In 2,500 trials using a GLM-5.2 baseline, turning on auto-approve raised utility but increased attack success from 29.2% to 95.6%.

> Restrictions on a shared capability can block legitimate work as well as malicious work, and allowed tools can leave unauthorized operations reachable through other execution paths.
