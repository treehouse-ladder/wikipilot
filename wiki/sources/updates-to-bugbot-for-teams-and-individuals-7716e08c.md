## Excerpts

> Bugbot is switching from a $40 per seat per month subscription to usage-based billing for Teams and Individual plans. The average Bugbot run costs $1.00-$1.50, depending on PR size and complexity. With usage billing, you can now choose the effort level Bugbot uses when reviewing PRs — users can configure Bugbot to think for longer and run deeper reviews, or set up custom logic that Cursor uses to dynamically determine review effort. With default effort, Bugbot finds 0.7 bugs per run, on average, and over 79% of these bugs are resolved by users at merge time. With high effort, Bugbot finds 0.95 bugs per run.
