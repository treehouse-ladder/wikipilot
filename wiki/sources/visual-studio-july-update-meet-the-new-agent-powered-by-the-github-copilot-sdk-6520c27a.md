## Excerpts

> Copilot Chat has a new Agent (Preview) option in the agent picker, built on the same GitHub Copilot SDK that powers the GitHub Copilot CLI. The idea is simple: get more tasks right the first time, with less back-and-forth to keep the agent on track.

> The release also introduces built-in .NET and Azure skills, organization-level custom instructions, Git branch context for chat and an opt-in C++ build tools discovery feature.

> Branches now join commits, changes, and pull requests as context you can attach to Copilot Chat. Right-click any branch in the Git Repository window and select Add to Chat to bring it into your conversation.
