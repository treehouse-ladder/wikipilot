## Excerpts

> The FINAL FANTASY X LP Vinyl Set -Eternal Calm- is a double LP pressed on transparent clear / light blue split vinyl, featuring 20 selected tracks from the original game. Both music releases are scheduled to launch on July 1, 2026. The set includes commemorative art by Tetsuya Nomura celebrating the 25th anniversary. Music is by Nobuo Uematsu, Masashi Hamauzu, and Junya Nakano. The package also includes an MP3 download code.
