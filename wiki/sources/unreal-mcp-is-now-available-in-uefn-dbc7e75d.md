## Excerpts

> Unreal MCP, the Model Context Protocol (MCP) plugin that shipped with UE 5.8, is now available in Unreal Editor for Fortnite (UEFN). UEFN embeds an MCP server inside the editor, so agentic coding tools such as Claude Code, Codex, or Cursor can connect to write Verse, configure devices, build UI with UMG, and run play sessions.

> Agents connected through Unreal MCP can read, write, and compile the Verse files in your project. Agents can describe the mechanic you want and write the code, kick off the compile, and report back on the result. It can also search across your Verse files, explain unfamiliar code, and keep iterating on compile errors until the build is green.

> Unreal MCP is built into UEFN, so there's no separate plugin to install. To get started, enable UEFN MCP toolset under beta access in your project settings, then generate the configuration that connects your agentic coding tool of choice to the editor.

> Agents can browse the device catalog, place Creative or Verse devices in your level, and edit their properties. This includes providing capabilities for writing and compiling Verse, placing and configuring devices, creating Scene Graph entities, building UI with UMG, and running play sessions to test.
