## Excerpts

> The harness and the model together determine how good the agent is, and Cursor has built several layers of measurement, maintaining public benchmarks alongside their own eval suite called CursorBench. Cursor approaches building the agent harness through vision-driven work where they form hypotheses about how to improve the experience, run experiments to test them, and iterate using quantitative and qualitative signals from evals and real usage, which depends on having the right online and offline instrumentation.
