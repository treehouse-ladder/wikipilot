## Excerpts

> North Mini Code is a small 30B parameter (3B active) open weights coding model released by Cohere that scores 27.6 on the Artificial Analysis Intelligence Index. It was released on June 9, 2026 under the Apache 2.0 license.

> North Mini Code generates output at 117.0 tokens per second and has a time to first token (TTFT) of 0.33s on Cohere's API. The model supports text input, outputs text, and has a 256k tokens context window.

> North Mini Code scores 27.6 on the Artificial Analysis Intelligence Index, placing it well above average among other open weight models of similar size (median: 9).
