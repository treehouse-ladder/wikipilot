## Excerpts

> Cohere released Command A+ on May 20, 2026: a 218B sparse Mixture-of-Experts model with 25B active parameters, Apache 2.0 licensed, that runs on as few as 2 H100 GPUs. The model is released under the Apache 2.0 license, which is OSI-approved and imposes no revenue caps, naming requirements, or use-case restrictions. Command A+ features native citation generation, W4A4 lossless quantization, and full Apache 2.0 licensing. Cohere's prior model, Command R+, shipped under CC-BY-NC 4.0 — meaning commercial deployment required an enterprise license from Cohere. Command A+ drops that requirement entirely.
