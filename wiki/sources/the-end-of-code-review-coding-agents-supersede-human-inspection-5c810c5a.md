## Excerpts

> Coding agents have crossed a threshold of capability at which traditional human code review is no longer a necessary component of a software quality pipeline.

> The argument rests on two main claims: every stated goal of code review can be served by agents at lower cost and higher throughput; and the naive integration in which agents write code and humans remain the mandatory reviewers is a dead end because it neither provides meaningful assurance nor scales with AI-assisted throughput.

> Code review has been the primary quality gate in software development since Fagan formalized code inspection in 1976; for five decades, having a human examine and comment on a colleague's changes before merge has been a cornerstone practice at organizations of every size.
