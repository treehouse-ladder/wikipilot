> After 12 major iterations (321 commits by coding agents, mostly Claude Code) Battle Drones runs on mobile and desktop. I have reviewed almost none of the code. Claude Code "Ultracode" burns tokens like there's no tomorrow, but it can also solve complex problems from a single prompt. In one version Claude ran over a thousand simulated playtest sessions and used the results to rebalance the existing units. The multiplayer-over-audio thing is a first for an RTS as far as I can tell.
