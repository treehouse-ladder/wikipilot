## Excerpts

> Capcom has created a suite of four different types of AI agent: Visual agents which 'look at the screen like a human' to detect technical issues; Predictive agents which predict where the game is 'likely to break next' and send swarms of 'test bots' to those areas; Data inefficiency agents which 'identify inefficiencies within massive datasets to optimize game performance'; and Institutional knowledge agents which lets developers refer to past data on how 'veteran engineers solved similar problems'.

> This system reportedly conducts 30,000+ hours of autonomous playtesting per month on Capcom's games. One verification task involving a character changing equipment would take human playtesters 5,280 hours to monitor, but Capcom's AI agents can screen and flag bugs in that process in about 72 hours.

> The only game to be named in Google's coverage of Capcom's AI testing tools is Monster Hunter Stories 3: Twisted Reflection, which launched on 13 March 2026.

> A huge volume of this checking and evaluation work is carried out while humans are asleep, and because the AI performs these checks in advance, humans no longer need to carry out enormous amounts of manual verification work themselves.
