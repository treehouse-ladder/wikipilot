## Excerpts

> Harness optimization enables automated agent creation by having an optimizer agent iteratively update the harness of target agents. Current studies evaluate optimizers solely by observing target agents' performance gains, and this indirect evaluation neglects optimizers' actions at intermediate steps, which are often erroneous and hinder agent performance. We propose priority ranking — a simple, low-cost design to directly evaluate harness optimizers — asking harness optimizers to rank components (e.g., tools) in a given harness by their potential to improve or hinder agent performance when updated.
