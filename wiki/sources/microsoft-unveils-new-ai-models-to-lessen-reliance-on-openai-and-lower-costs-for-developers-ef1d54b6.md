## Excerpts

> Microsoft announced MAI-Code-1-Flash at its Build developer conference in San Francisco on Tuesday, a model that takes written descriptions from people and spits out source code for applications and websites.

> In addition to MAI-Code-1-Flash, Microsoft is introducing MAI-Thinking-1, a reasoning model, built for high efficiency and performance at a low-token cost.

> MAI-Thinking-1 is a 35-billion active parameter reasoning model trained on commercially licensed data... a mid-sized sparse Mixture of Experts model with 35 billion active parameters and a 256,000-token context window, trained from scratch on enterprise-grade, commercially licensed data, without distillation from any third-party model.

> MAI-Thinking-1 is available in private preview via the Microsoft Foundry platform, and Microsoft said that it matches Anthropic's Claude Opus 4.6 model released in February on coding abilities on the SWE Bench Pro benchmark.
