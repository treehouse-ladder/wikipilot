## Excerpts

> Added a maxEffortLevel setting (top-level or per model under modelSettings) that caps the effort level on every provider, including Bedrock, Vertex and Foundry, while allowing users to still pick a lower level.

> Added --system-prompt-snapshot off to render the system prompt fresh on every request instead of reusing the conversation's recorded prompt.

> Fixed Cowork scheduled tasks in the cloud failing at startup for organizations whose managed settings require sandboxing. Fixed /context and other local command output rendering blank on mobile clients.
