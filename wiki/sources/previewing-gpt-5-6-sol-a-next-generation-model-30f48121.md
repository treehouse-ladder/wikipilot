> We're beginning a limited preview of the GPT-5.6 series: Sol, our new flagship model; Terra, a balanced model for everyday work; and Luna, a fast and affordable model. GPT-5.6 Sol is OpenAI's strongest model yet.

> The GPT-5.6 family advances the frontier on software engineering, computer use, professional knowledge work, scientific research, and cybersecurity. For coding workflows, GPT-5.6 Sol sets a new state of the art on Terminal-Bench 2.1, which tests command-line workflows requiring planning, iteration, and tool coordination. GPT-5.6 Sol is OpenAI's most capable model yet for cybersecurity.

> GPT-5.6 is priced per 1M tokens across three model sizes: Sol is $5 input / $30 output; Terra is $2.50 input / $15 output; and Luna is $1 input / $6 output.
