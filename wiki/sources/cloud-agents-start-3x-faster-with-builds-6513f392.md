## Excerpts

> Builds are ready-to-use copies of your development environment that Cursor prepares in the background. Agents boot into a ready environment instead of setting up from scratch each session.

> Internally, environments now boot 10x faster, with 3x faster time to first token. Builds are included with Cloud Agents at no additional cost.

> Cursor runs a new build of the environment regularly, and when a build succeeds, it becomes the environment future agents start from.

> If a bad commit or dependency update breaks an environment, agents keep using the last successful build, and you are notified of the issue while your agents keep working.
