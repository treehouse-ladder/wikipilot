## Excerpts

> We address the challenge of creating dynamic non-player characters (NPCs) in gaming environments that enable both functional task execution and persona-consistent dialogue generation. We coin 'deflanderization' to describe the failure mode where character traits dominate to the exclusion of task-relevant behavior. Our work explores prompt-engineering and fine-tuning strategies that balance authenticity of in-character speech with the procedural requirements of game dialogue (quest-giving, hints, transactions).
