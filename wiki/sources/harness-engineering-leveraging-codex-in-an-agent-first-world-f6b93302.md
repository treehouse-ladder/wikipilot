## Excerpts

> The software engineering team's primary job is no longer to write code, but to design environments, specify intent, and build feedback loops that allow Codex agents to do reliable work. Humans steer, agents execute.

> Every line of code—application logic, tests, CI configuration, documentation, observability, and internal tooling—has been written by Codex. We estimate we built this in about 1/10th the time it would have taken to write the code by hand.

> The repository contains on the order of a million lines of code, with roughly 1,500 pull requests merged by a team of just three engineers driving Codex, translating to an average throughput of 3.5 PRs per engineer per day, with throughput increasing as the team grew to seven engineers.

> One of the biggest challenges in making agents effective at large and complex tasks is context management. One of the earliest lessons was to give Codex a map, not a 1,000-page instruction manual.
