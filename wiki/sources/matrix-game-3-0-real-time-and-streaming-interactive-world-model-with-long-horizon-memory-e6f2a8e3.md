## Excerpts

> We present Matrix-Game 3.0, a memory-augmented interactive world model designed for 720p real-time longform video generation. Building upon Matrix-Game 2.0, we introduce systematic improvements across data, model, and inference, first developing an upgraded industrial-scale infinite data engine that integrates Unreal Engine-based synthetic data, large-scale automated collection from AAA games, and real-world video augmentation to produce high-quality Video-Pose-Action-Prompt quadruplet data at scale. We employ a multi-segment autoregressive distillation strategy to support 40fps real-time generation at 720p resolution with a 5B model while maintaining stable memory consistency over minute-long sequences.
