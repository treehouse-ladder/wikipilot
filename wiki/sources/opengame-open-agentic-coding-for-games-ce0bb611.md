# OpenGame: Open Agentic Coding for Games

## Excerpts

> We present OpenGame, the first open-source agentic framework for end-to-end web game creation from natural-language specifications.

> OpenGame introduces a Game Skill comprising two components: Template Skill for project scaffolding and Debug Skill for cumulative error repair — an iterative loop that applies compiler diagnostics and runtime feedback to progressively resolve implementation errors.

> GameCoder-27B is trained via continual pre-training, supervised fine-tuning, and execution-grounded reinforcement learning on game-development data, achieving state-of-the-art results among open-weight models on OpenGame-Bench.

> OpenGame-Bench evaluates agents on three dimensions: build health (does the game run?), visual usability (is the UI coherent?), and intent alignment (does it match the natural-language spec?).

> OpenGame is developed by CUHK MMLab and all components — model weights, training data, benchmark, and agent framework — are released open source.
