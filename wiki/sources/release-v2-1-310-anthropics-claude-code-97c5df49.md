## Excerpts

> Unlocked the Monitor tool and plugin monitors on Bedrock, Vertex, and Foundry, and when telemetry or nonessential traffic is disabled.

> Added a managed setting that blocks monitors from plugins that aren't force-enabled.

> Added idle compaction to the VS Code chat panel and the Desktop Code tab: the summary is computed while you're away and only used if your next message comes an hour or more later.

> Fixed compaction after a "Prompt is too long" error keeping too much of a conversation with dense text such as base64 or SVG.

> Fixed requests failing behind some gateways and compatible servers that reject the effort beta value or mid-conversation system messages, by retrying without them.

> Disabled git askpass for plugin and marketplace clones.
