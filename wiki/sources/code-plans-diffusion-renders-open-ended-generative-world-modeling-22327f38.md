## Excerpts

> We present a generative world modeling framework that combines LLM-generated code plans (specifying scene structure, physics rules, and entity behaviors as executable programs) with diffusion-model rendering of the resulting scene graph. The hybrid approach yields controllable, consistent world generation: code plans enforce logical structure while diffusion rendering supplies photorealistic visual diversity.

> In open-ended game-environment generation benchmarks, Code Plans + Diffusion Renders outperforms pure diffusion baselines on structural consistency (collision geometry, reachability) while matching them on visual quality metrics. The code-plan layer also enables designer-friendly natural-language editing of generated worlds.
