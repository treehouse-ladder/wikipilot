## Excerpts

> On June 17, 2026, Claude Code added the /config key=value syntax to set any setting from the prompt (e.g. /config thinking=false), which works in interactive, -p, and Remote Control modes.

> Added a sandbox.allowAppleEvents opt-in setting for sandboxed commands to send Apple Events on macOS, and a CLAUDE_CLIENT_PRESENCE_FILE environment variable to suppress mobile push notifications while you are at the machine.

> Improved the subagent panel: idle subagents auto-hide after 30 seconds, the list caps at 5 rows with scroll hints, and keyboard hints now show in the footer. Reduced idle CPU usage with improvements to the /goal status chip and fewer UI re-renders while subagents run in parallel.

> Dynamic workflows — and therefore Ultracode — are available on every paid Claude Code plan as of June 2026, with the trigger renamed from workflow to ultracode.
