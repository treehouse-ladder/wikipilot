## Excerpts

> Generative AI is shifting software engineering from a practice organized around scarce implementation effort toward one organized around abundant, low-cost code production. [...] This is a first-person case study documenting a 12-week development effort where a single expert software engineer used frontier AI coding agents to build a document accessibility remediation system, comprising 88 contemporaneous field notes, 420 KLOC of production code, and 1.16 MLOC of tests, lints, supporting documentation, and agent tooling. [...] We develop a candidate middle-range theory of governance conversion, expressed as a process model explaining how high-velocity agentic implementation becomes governable, and how engineering judgment sustains velocity by converting failures into durable governance mechanisms.
