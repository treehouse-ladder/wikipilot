> Developers can now build with Muse Spark 1.1 via the new Meta Model API, now in public preview.

> Muse Spark 1.1 has a context window of 1 million tokens. The model can actively manage its context window by remembering actions, retrieving information from earlier work, and compacting in a way that keeps critical steps for later work.

> Muse Spark 1.1 features massive million-token context, full multimodal support (images, video, PDFs), built-in search with citations, strong reasoning, top-tier coding abilities, structured output, and parallel tool calling.

> Muse Spark 1.1 achieved the highest score of 88.1 on the MCP Atlas benchmark for scaled tool use and 54.7 on JobBench for professional tool use. It scored 80.0 on Terminal-Bench 2.1, 61.5 on SWE-Bench Pro, and topped Humanity's Last Exam with 62.1.
