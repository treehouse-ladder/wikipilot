# Getting started with Unity AI: open beta user guide

## Excerpts

> Unity AI is a suite of tools for automating tasks and generating assets within and outside the Unity Editor, including the AI Assistant, Generators, AI Gateway, and MCP Server.

> As of May 12, 2026, users can access it using Unity Editor 6.3+.

> Unity AI gives developers access to an in-project agentic assistant, which leverages deep context from projects and is built specifically for Unity workflows.

> The assistant can understand scenes, inspect GameObjects and components, help drive Editor actions, and verify that changes behave as intended.
