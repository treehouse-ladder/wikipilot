## Excerpts

> Auto-review is a new run mode that lets Cursor work for longer with fewer approval prompts, while keeping execution safe. It applies to Shell, MCP, and Fetch tool calls.

> In Auto-review mode, Cursor will automatically review and approve actions that meet a safety threshold, pausing for human approval on higher-risk operations like file deletion or network requests to unfamiliar domains.

> Auto-review is part of our broader effort to let developers delegate more of the verification loop to the agent while maintaining meaningful control over consequential actions.
