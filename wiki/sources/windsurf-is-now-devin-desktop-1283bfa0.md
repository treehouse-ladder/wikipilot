## Excerpts

> Devin Desktop supports the Agent Client Protocol (ACP), and is now compatible with Codex, Claude Agent, OpenCode, and any other ACP-compatible agent. This lets users manage multiple agents from one surface and share context between them.

> We built on the IDE foundation of Windsurf to introduce the command center for managing all your agents in one place, allowing users to manage every local and cloud agent from a single Kanban view.

> Devin Desktop also introduced Spaces, a new way to share context between agents while grouping sessions, PRs, files, and context.
