## Excerpts

> > GPT-5.3-Codex is our most capable agentic coding model to date. It advances both the frontier coding performance of GPT-5.2-Codex and the reasoning and professional knowledge capabilities of GPT-5.2, together in one model, which is also 25% faster.
> 
> > On SWE-Bench Pro (Public), GPT-5.3-Codex scored 56.8% (vs. 56.4% for GPT-5.2-Codex and 55.6% for GPT-5.2). On Terminal-Bench 2.0, it scored 77.3% (vs. 64.0% for GPT-5.2-Codex and 62.2% for GPT-5.2). On the OSWorld-Verified agentic computer-use benchmark, the model scored 64.7% (vs. 38.2% for GPT-5.2-Codex and 37.9% for GPT-5.2).
> 
> > GPT-5.3-Codex is the first model that was instrumental in creating itself—the Codex team used early versions to debug its own training, manage its own deployment, and diagnose test results and evaluations.
> 
> > Codex is moving beyond writing code to using it as a tool to operate a computer and complete work end to end.
