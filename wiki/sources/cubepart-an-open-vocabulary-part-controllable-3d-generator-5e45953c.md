## Excerpts

> CubePart is the first generative AI framework that allows open-vocabulary, part-controllable 3D mesh generation. CubePart outputs an assembled set of distinct, functional, and accurately-labeled meshes that match the developer's programming needs out of the box.

> CubePart expands the concept of fixed schemas introduced with 4D Generation to empower a creator to define the list of parts an object should be broken into. The set of meshes generated by CubePart drop straight into the game engine and can be controlled by animation, physics, and gameplay scripts without manual cleanup.

> To train CubePart, Roblox created a dataset featuring more than 460,000 assets—over 11 times larger than previous public datasets—and 2.02 million parts.
