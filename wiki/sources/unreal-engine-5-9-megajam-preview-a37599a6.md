## Excerpts

> Unreal MCP launches automatically with the editor, delivers more reliable connections, and expands its toolsets to cover rendering, source control, profiling, debugging, gameplay testing, geometry, audio, UI, and level creation.

> New integrations with Lore enable AI agents to manage project changes and automate source control workflows.

> A new Fab toolset lets agents search the catalog, browse the user's library, and install assets into projects.

> Known issue: New projects may start with no level-editing tools, because the Toolset plugins are off by default. The workaround is to enable All Toolsets before connecting an agent.

> The Unreal Engine 5.9 MegaJam Preview was released on November 9, 2026, ahead of the 2026 Epic AI MegaJam, which runs November 12-15.
