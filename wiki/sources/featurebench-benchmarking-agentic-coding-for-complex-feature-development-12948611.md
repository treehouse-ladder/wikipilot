## Excerpts

> FeatureBench is a benchmark designed to evaluate agentic coding performance in end-to-end, feature-oriented software development. The benchmark comprises 200 evaluation tasks and 3825 executable environments from 24 open source GitHub repositories. FeatureBench incorporates an execution-based evaluation protocol and a scalable test-driven method that automatically derives tasks from code repositories with minimal human effort. Claude 4.5 Opus, which achieves 74.4% resolved rate on SWE-bench, succeeds on only 11.0% of tasks, highlighting the gap between traditional bug-fixing benchmarks and complex feature development.
