## Excerpts

> Unity MCP acts as a bridge, allowing AI assistants (like Claude, Cursor) to interact directly with your Unity Editor via a local MCP (Model Context Protocol) Client. Give your LLM tools to manage assets, control scenes, edit scripts, and automate tasks within Unity. Recent versions include new manage_profiler tools (version 9.6.3 beta) with profiler session control and Frame Debugger capabilities, and manage_physics tools (version 9.6.2) with physics settings, layer collision matrix, and various physics queries.
