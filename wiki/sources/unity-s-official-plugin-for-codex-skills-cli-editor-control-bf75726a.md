## Excerpts

> Unity's announcement says the plugin gives Codex 31 skills written by the Unity teams that own each feature, covering areas such as UI, 2D, URP, audio, IAP, and multiplayer. It also includes a unity-cli skill for working from the terminal.

> Setup takes two commands from your terminal, or one click from the Codex directory. The plugin is built for Unity 6 and up.

> A Unity staff post says the Codex plugin isn't an MCP server, so it doesn't hook into your running Editor; Unity's AI overview, by contrast, describes the plugin as bundling the CLI together with Unity's skills and the MCP server.
