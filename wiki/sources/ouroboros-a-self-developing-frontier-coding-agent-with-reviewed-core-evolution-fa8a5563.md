## Excerpts

> Ouroboros is a self-developing agent harness whose tools, prompts, context assembly, and core implementation improve through reviewed commits that become the runtime for later work.

> Core evolution proceeds in two modes: in recursive free evolution, improvement is itself a task and completing one evolution cycle can schedule the next, while in experience-driven core evolution, ordinary work and social interaction expose bugs, rough edges, and inefficient context construction that lead to reviewed structural changes.
