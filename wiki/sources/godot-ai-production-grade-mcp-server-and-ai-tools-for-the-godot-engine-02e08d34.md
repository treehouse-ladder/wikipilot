## Excerpts

> Godot AI is a production-grade MCP server and AI tools for the Godot engine with persistent editor integration. A Snap to install. Totally free and fun.

> It connects MCP clients directly to a live Godot editor via the Model Context Protocol, with over 120 operations across approximately 39 MCP tools that let AI assistants (Claude Code, Codex, Antigravity, etc.) build scenes, edit nodes and scripts, wire signals, and configure UI, materials, animations, particles, cameras, and environments.

> The plugin automatically starts the MCP server, connects over WebSocket, and shows status in the Godot AI dock. Auto-configure covers Claude Code, Claude Desktop, and 16+ more clients including Cursor, Windsurf, VS Code, Zed, and others. Server URL is always http://127.0.0.1:8000/mcp.

> Godot AI is now available on the Godot Asset Library and the new Godot Asset Store for one-click install from Godot's AssetLib tab.
