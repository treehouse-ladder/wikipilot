## Excerpts

> Enterprise owners can now govern the GitHub Copilot app and Copilot cloud agent with enterprise managed settings, the same centrally managed policies used to control Copilot across enterprises.

> Enterprise owners can define guardrails such as which plugins and marketplaces developers can use through a managed-settings.json file.

> Copilot cloud agent is an asynchronous, autonomous background agent that analyzes issue contents and opens a draft pull request.
