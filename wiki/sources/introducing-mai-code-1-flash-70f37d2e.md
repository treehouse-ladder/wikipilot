## Excerpts

> MAI-Code-1-Flash is a new Microsoft coding model built for fast, efficient assistance in everyday developer workflows and is built end-to-end by Microsoft using clean and appropriately licensed data.

> MAI-Code-1-Flash outperforms Claude Haiku 4.5 across all four core coding benchmarks tested, including a 16-point lead on SWE-Bench Pro (51.2% vs. 35.2%), and can solve harder coding tasks with up to 60% fewer tokens on SWE-Bench Verified.

> MAI-Code-1-Flash rolls out to all GitHub Copilot plans today.
