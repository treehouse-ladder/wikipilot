## Excerpts

> A hard budget cap is the feature that lets you say "after $X/month, cut this thing off and return errors". | Coding agents greatly reduce the friction of spinning up code that can do useful things. Sometimes those things cost money. | Hard budget caps need to be the default. If you want to live dangerously you should be able to do that, but it needs to be on an opt-in basis. | It would be great if agents started biasing towards recommending providers with hard budget caps, and warning new and inexperienced builders against deploying applications using uncapped services.
