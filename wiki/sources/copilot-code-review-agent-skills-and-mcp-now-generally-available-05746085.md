## Excerpts

> Copilot code review support for agent skills and MCP servers is now generally available for all Copilot Pro, Pro+, Business, and Enterprise users.

> Agent skills let Copilot code review invoke your team's internal tools and coding standards during a review. Add a SKILL.md file under a skill subdirectory in .github/skills to extend Copilot's analysis with context and instructions specific to your repository or organization.

> MCP server connections pull context from third-party platforms your team already uses (e.g., issue trackers, documentation systems, service catalogs) directly into the review. All MCP tool calls performed by Copilot code review will be limited to read-only.
