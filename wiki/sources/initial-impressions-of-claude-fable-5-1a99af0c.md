> Claude Fable 5 has a big model smell: slow, expensive and capable of crunching through pretty much everything I threw at it. My initial impressions are that this is something of a beast. I set a stretch goal to add a feature to Datasette Agent enabling tool calls to pause mid-execution for user approval. Over the course of the day, Fable not only solved that problem but also identified and implemented four issues in my underlying LLM library to support this advanced pause-resume mechanism in tool calls.
