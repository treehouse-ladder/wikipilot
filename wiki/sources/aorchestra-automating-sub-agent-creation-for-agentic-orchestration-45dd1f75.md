## Excerpts

> AOrchestra is an orchestrator-centric agentic system that treats sub-agents as dynamically creatable executors via a unified 4-tuple interface (Instruction, Context, Tools, Model), enabling on-demand specialization with task-sufficient context and explicit capability control.

> Across three challenging benchmarks (GAIA, SWE-Bench, Terminal-Bench), AOrchestra achieves 16.28% relative improvement against the strongest baseline when paired with Gemini-3-Flash.
