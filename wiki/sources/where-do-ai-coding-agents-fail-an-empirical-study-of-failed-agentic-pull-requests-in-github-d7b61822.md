## Excerpts

> We examined 33k agent-authored PRs made by five coding agents across GitHub. Tasks related to documentation, CI, and build update achieve the highest merge success, whereas performance and bug-fix tasks perform the worst.

> Not-merged PRs tend to involve larger code changes, touch more files, and often do not pass the project's CI/CD pipeline validation.

> We characterized merged and not-merged PRs along four broad dimensions: 1) merge outcomes across task types, 2) code changes, 3) CI build results, and 4) review dynamics.
