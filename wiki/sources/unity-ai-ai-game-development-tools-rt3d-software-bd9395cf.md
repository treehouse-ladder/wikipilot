## Excerpts

> Unity AI gives you access to an in-project agentic assistant, which leverages deep context from your projects and is built specifically for Unity workflows. The core features include the Unity AI Assistant, AI Gateway, and Unity's Official MCP Server. Generators include Animation Generator (creates humanoid animations from a prompt), Texture Generator (produces 2D textures), Material Generator (builds physically-based materials), Sprite Generator (outputs 2D images), and Sound Generator (generates ambient sounds and effects). The Unity AI assistant currently uses large language models from OpenAI and Meta (GPT and Llama, respectively) to answer user questions, generate code, and run agentic actions.
