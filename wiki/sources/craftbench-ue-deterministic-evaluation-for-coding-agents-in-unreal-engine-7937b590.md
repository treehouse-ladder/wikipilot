## Excerpts

> CraftBench-UE is an evaluation harness that runs agents in an isolated Unreal Engine environment, reconstructs their saved submissions in fresh projects, and applies deterministic build, asset, and runtime checks without an LLM judge.

> The benchmark consists of 70 tasks spanning C++ source, Blueprint assets, and editor scripting.

> Across the 10 paired tasks, C++ completion rates exceed Blueprint by 30.0 and 42.9 percentage points in the two tool configurations.

> Building gameplay features in a game engine requires more than code: code that compiles and runs does not necessarily implement the requested gameplay.
