## Excerpts

> GameDirector introduces a two-stage architecture that separates gameplay logic (physics, rules, agent behavior) from visual rendering, enabling players to reconfigure the aesthetic layer of game worlds without altering underlying mechanics. The system uses a learned world model to predict game-state transitions independently of the renderer, allowing real-time player-driven visual style switching.

> Evaluated on procedurally-generated 2D platformer and 3D exploration environments, GameDirector achieves competitive game-state prediction accuracy while supporting on-the-fly renderer swaps (pixel art → photorealistic → stylized), opening new design space for player-customizable aesthetics in procedural games.
