## Excerpts

> Kimodo is the first AI motion-generation model integrated with the guided animation framework in Unreal Engine 5.9 Preview, enabling animators to generate character motion right inside Sequencer. Animators can describe a motion with a text prompt, draw a spline path for the character to follow, and set target poses at specific frames.

> The Animotive Kimodo Unreal Engine plugin ships today, with Blender and Maya integrations to follow.
