## Excerpts

> Background commands are now stopped only on critically low memory (not mild pressure), with a new visible warning when memory is critical.

> CLAUDE_CODE_MCP_STARTUP_WAIT_MS bounds how long the first non-interactive turn waits for connecting MCP servers (0 = do not wait).

> The new SystemPromptCustom type — {"type": "custom", "prompt": "...", "snapshot": false} lets SDK users control whether the system prompt is rebuilt every request or reused from the first.

> The monitoring docs now document tool.output span events and request-body correlation IDs for the first time.
