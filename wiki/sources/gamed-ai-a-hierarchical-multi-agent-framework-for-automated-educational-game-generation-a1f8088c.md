## Excerpts

> GamED.AI is a hierarchical multi-agent framework that transforms instructor-provided questions into Bloom's-aligned educational games validated through formal mechanic contracts. It is built on a LangGraph DAG with phase-specific sub-graphs, deterministic Quality Gates, and typed Pydantic schemas. The system generates validated games in under 60 seconds at $0.46 per game—achieving 73% token reduction over ReAct agents and 90% validation pass rate across 200 test questions covering all 15 mechanics.
