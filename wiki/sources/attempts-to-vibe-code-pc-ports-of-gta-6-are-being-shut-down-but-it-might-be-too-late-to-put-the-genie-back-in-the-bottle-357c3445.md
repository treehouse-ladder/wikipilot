> Attempts To Vibe-Code PC Ports Of GTA 6 Are Being Shut Down, But It Might Be Too Late To Put The Genie Back In The Bottle. The Project Leonida Discord was taken down after a request from Rockstar and Take-Two. Take-Two also asked GitHub to remove the main Project Leonida repository and its forks; per a DMCA notice GitHub posted, the takedown applied to all 3,007 repositories in the fork network. Unofficial porting efforts are being undertaken with the help of Claude AI.
