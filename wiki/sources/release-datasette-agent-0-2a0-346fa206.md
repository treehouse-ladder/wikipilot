## Excerpts

> datasette-agent 0.2a0 includes a new built-in save_query tool that allows the agent to save SQL it has written as a Datasette stored query.

> Saving always requires human approval — the agent shows the full SQL plus the proposed name, database and visibility, and nothing is stored until you click Yes.

> The ask_user() feature was enabled by the new LLM alpha built with the help of Claude Fable 5.
