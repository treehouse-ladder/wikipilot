## Excerpts

> With this release, cloud agents can automatically pick up work in response to events, hold a goal until it's met, and stay on course through long-running sessions.

> Event Subscriptions: Cursor Agent subscribes to an event source (a thread or conversation) and wakes when something happens.

> Non-Interrupting Follow-ups: Follow-ups wait for the next tool call instead of cutting the agent off mid-action.

> Custom Modes: You can use any skill as a Custom Mode, a skill that stays pinned in the chat.

> Subagent Isolation: Subagents can now run on their own virtual machines. Each gets an isolated copy of the project with clean context in its own cloud environment.

> Long-Lived Goals: Use /goal to give the agent a long-lived objective to work towards until it's fully complete.
