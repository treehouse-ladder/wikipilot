## Excerpts

> The system uses four roles modeled on a game studio: the Designer turns user instructions and reviewer feedback into plans; the Builder implements candidate games; the Player is a coding-native agent that writes reusable policies run through programmatic interfaces rather than a GUI; the Reviewer judges the games. The method reaches a score of 77.89 on GameCraft-Bench (state-of-the-art) and a strict task success rate of 53.2% on GameASG-Bench, a 34.1% improvement over the same-model baseline.
