### agentic-coding (PR #366 — 3 sources, 4 pages)

**PERFOPT-Bench**: first benchmark targeting software performance optimization specifically (algorithmic complexity reduction + hardware efficiency). Tests coding agents on tasks where correctness is necessary but not sufficient — the output must also run faster. Extends beyond SWE-Bench's correctness-only framing. [[perfopt-bench-evaluating-coding-agents-on-software-performance-optimization-0c17f7ce]]

**Cheap Code Costly Judgment** (arXiv): case study on governable agentic software engineering. Key finding: governance frameworks (human-in-the-loop checkpoints, approval gates) significantly reduce defect rates but slow throughput; no-code-review regimes are faster but introduce structural drift. Identifies a governance vs. velocity tension as a first-class design decision for agentic SE adoption. New dispute: PERFOPT-Bench harness-vs-model performance attribution. New open question: Does governance overhead scale sub-linearly as agents improve? [[cheap-code-costly-judgment-a-case-study-on-governable-agentic-software-engineering-7c0872b9]]

**Datasette code-frequency chart on GitHub**: Simon Willison's release artifact; shows coding agent commit cadence patterns over the Datasette project history — a real-world data point on how agentic-coding contributions appear in version control. [[datasette-code-frequency-chart-on-github-669accad]]
