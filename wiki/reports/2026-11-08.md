# Daily Research Report — 2026-11-08

## Today's brief

- **Unity Codex Skills CLI plugin**: Unity shipped an official first-party plugin bringing its engineering Skills, CLI, and MCP editor control to OpenAI Codex — command-line editor control, 1-click Build, 1-click Run Test, with agent tools usable as Editor actions [[unity-s-official-plugin-for-codex-skills-cli-editor-control-bf75726a]]. **Why it matters to you:** Codex is now a sanctioned second agent host (after Claude Code) for driving the Unity Editor from the same CLI harness that drives your repo — vendor-tested agentic engine control, no community-script glue.
- **Cursor live-app development**: Cursor's agent can now automatically rebuild/restart your app on code changes and iterate through an inline browser without leaving the IDE [[build-live-apps-in-cursor-c30b3225]]. **Why it matters to you:** tightens the inner build-run-observe loop so a coding agent sees the effect of its own edits live — less context-switching when prototyping a game or tool build (vendor feature, no measured uplift yet).
- **[[elevenlabs-sfx]] (SFX v3)**: ElevenLabs' new `eleven_text_to_sound_v3` is now the default sound-effects model, adds multi-part prompt following (events emitted in sequence order), and is priced at 40 credits/second for a specified 0.5–30 s duration; `eleven_text_to_sound_v2` is deprecated (removed Mar 1 2027) [[sfx-v3-api-generate-sound-effects-from-multi-part-prompts-6992a7c6]]. **Why it matters to you:** a drop-in SFX-generation step for your game-audio pipeline — multi-part prompts let you script a whole sequence of effects in a single call.
- **[[eleven-music]] Music v2.5**: ElevenLabs made `music_v2_5` the default music model after it was preferred in a 47,885-pair blind test, with the largest gains on vocal-led and acoustic-heavy genres; `music_v1` is deprecated (removed Jan 31 2027) [[elevenlabs-introduces-music-v2-5-its-best-music-model-yet-e742a57d]]. **Why it matters to you:** measurably better generated-soundtrack quality for a game, plus a migration deadline if any of your pipelines still pin v1.
