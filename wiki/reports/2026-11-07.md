# Daily Research Report — 2026-11-07

## Today's brief

- **[[elevenlabs]] Eleven v4 / v4 Turbo** supersede Eleven v3; v4 Turbo returns first audio at ~100 ms median latency (~150 ms time-to-first-speech) across 90+ languages, API-priced ~$0.04/min (Turbo) / ~$0.08/min (v4) [[eleven-v4-our-most-expressive-text-to-speech-ai-model-yet-028b20a4]]. **Why it matters:** ~100 ms latency puts real-time generated NPC dialogue within reach in-engine — a direct swap-in for the voice-NPC pipeline and a head-to-head competitor to [[inworld-realtime-tts-2]].
- **[[suno]] commercial use is now documented**: songs made and downloaded while on a paid Pro or Premier plan carry commercial rights including Spotify/Apple distribution; free-tier downloads are personal/non-commercial with no retroactive license [[can-i-distribute-my-songs-to-spotify-etc-25684551]]. **Why it matters:** resolves the standing "can I legally ship Suno music in my game?" question — a non-enterprise paid plan clears an AI soundtrack for a commercial release.
- **Unity is in buyout talks with Saudi Arabia's PIF + Silver Lake**, a reported leveraged buyout valuing it ~$25B (vs ~$21.5B public price) [[unity-is-in-1-5-billion-buyout-talks-with-saudi-arabia-s-pif-b200f894]] [[report-silver-lake-and-the-saudi-arabia-pif-hold-talks-with-unity-to-explore-acquisition-06ae03c1]]. **Why it matters:** a PIF-led take-private of a primary small-studio engine could reshape Unity's licensing and roadmap — worth factoring in before committing new projects to it (still talks, not a signed deal).
- **Claude Code v2.1.319** patches a worktree sandbox escape, a Bash permission bypass via a crafted env prefix, and a sed call that could skip the permission check in accept-edits/auto mode; it also adds `permissions.denyInsteadOfPrompting`, lets MCP tasks run in the background, and makes "auto mode behind gateways" deny unverifiable calls [[release-v2-1-319-anthropics-claude-code-7cf21137]]. **Why it matters:** if you run parallel subagents in accept-edits/auto mode these are upgrade-now security fixes.
