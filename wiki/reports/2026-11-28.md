### generative-media-models
**PAN 2** (MBZUAI Institute of Foundation Models): 29B-parameter MMDiT general-purpose interactable video world model. Given observation (image + text) + action descriptions, simulates resulting world state as up to 20s video at 704×1248/24fps. Architecture: MMDiT backbone + Qwen3.5-9B text encoder + Wan 2.2 VAE decoder. Apache-2.0 on HuggingFace (`IFM/PAN2`). Ships with `pan2-guardrail` stack. Agentic planning use case: run PAN 2 as forward model to simulate N candidate action sequences before committing. New entity page [[pan-2]] created.

### ai-in-game-dev
**Meshy 7.5** (rolled out 2026-11-24–27): New Low-Poly mode returns both high-poly and ~2%-polycount low-poly mesh with baked normal map in a single call (10 extra credits); new UV-unwrapping algorithm with lowest angle/area distortion vs Hi3D 3.0 and Tripo 3.1 on 33-object test; 99.9% multilingual text recovery on 42-object test. Entity page updated: `model_ids` +meshy-7.5, `last_release` 2026-11-27.

### agentic-coding
**Anthropic Messages API Rust migration** (via agentic coding pipeline): Production Python API used as a **verifier** — running both Python+Rust versions on live traffic, comparing outputs automatically. Three-loop architecture: fast inner loop (sandbox + local checks), slow outer loop (production validation after PR review), memory loop (agent learns from mistakes). Result: ~70% less CPU per request, ~20% faster median TTFT, shipped without downtime or feature freeze. Key meta-claim: **"verification is the new bottleneck"** — agents can generate code fast enough that the main constraint is now how quickly you can verify results.
