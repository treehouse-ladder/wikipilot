## Key findings

**ai-in-game-dev (summary-affecting):** Unity shipped its first-party Claude Code plugin — 29 Unity-authored engineering skills, Unity CLI, and MCP server for live Editor control in a single install. This is the first engine-vendor IDE-agent integration from a major game engine, crossing a structural threshold from "third-party MCP servers" to "engine-native agentic tooling." Separately, Puffin-World (HuggingFace) introduces a unified multimodal world model with Physics + Geometry + Appearance as native 3D world states, establishing a third research frontier alongside game-engine-native AI assistants and procedural content generation. The ai-in-game-dev Summary was regenerated to reflect both developments.

**agentic-coding:** Claude Code v2.1.268 adds a WebFetch tool hard timeout of 300 seconds, preventing stuck HTTP calls from wedging autonomous Routines-style sessions indefinitely. Simon Willison documents end-to-end Blender 3D asset creation (mesh generation, UV unwrapping, material assignment) driven by frontier LLMs via agentic-coding pipelines on macOS — extending the agentic workflow into game/3D content generation.

**games-of-note:** Xbox is publishing Hideo Kojima's *Physint* after PlayStation Studios notified Kojima Productions by email in mid-June 2026 that it was ending its involvement — Kojima spent three months finding a replacement publisher. The Rockstar IWGB employment tribunal opened in Glasgow (Sep 10), with 34 dismissed workers (31 IWGB members) alleging union-busting; the hearing runs through Oct 16. Riot Games co-founder Marc Merrill signalled at PAX West that the studio is exploring premium (non-F2P) games for the first time. Tim Schafer reframed Double Fine's post-Xbox position: the studio "never tried to lose money" but acknowledges no profitability level would have saved it without a breakout hit post-Phil Spencer; now independent and running Kickstarter.

**frontier-models / game-music:** Sentinel-only entries. Sakana AI's Fugu Max/Ultra v2 candidate was from `sakana.ai` (not in `allowlist_domains`); game-music candidates were from non-allowlisted domains.
