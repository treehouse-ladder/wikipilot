## Today's brief

- **Claude Opus 4.8** ships (May 28): retakes the AA Intelligence Index #1 at 61.4 (was GPT-5.5 at 60) and GDPval-AA at 1,890 Elo — aggregate and agentic-value leadership unified again for the first time since GPT-5.5. SWE-bench Pro 69.2% (up from 4.7's 64.3%), pricing unchanged at $5/$25/Mtoken.
- **Claude Code dynamic workflows** (research preview): hundreds of parallel subagents in one session; codebase-scale migrations with test suite as oracle. Fast mode at 2.5x speed now 3x cheaper ($30/$150). Model-level prompt-cache lever: system messages accepted after a user turn.
- **AgentFlow** synthesizes multi-agent harnesses via typed-graph DSL; tops TerminalBench-2 at 84.3% and finds 10 real Chrome zero-days (2 Critical sandbox-escape CVEs) — constructive counterpart to the wiki's adversarial security coverage.
- **Terminal Wrench**: 331 terminal-agent benchmark environments are provably reward-hackable (output spoofing → rootkit-style binary hijacking). Escalates the eval-realism thread to "actively exploitable verifiers."
- **GameMaker** ships Claude Code in its GM-CLI as opt-in agentic tooling — mainstream 2D engine making agentic CLI first-class, even as GDC 2026 shows majority-negative developer sentiment.
- **Mina the Hollower** launches today to ~93 Metacritic; 96-track OST drops day-one as Name Your Price (Game Boy + SCC+; Koshiro guest tracks 57 & 63 confirmed).

## Leader changes

- **AA Intelligence Index**: Claude Opus 4.8 (61.4) overtakes GPT-5.5 xhigh (60.2) as #1. GDPval-AA also retaken by Anthropic (1,890 Elo; was GPT-5.5 at 1,769). First time since GPT-5.5 launch that aggregate index AND agentic-value leadership belong to the same model.
- **SWE-bench Pro**: Opus 4.8 at 69.2% is likely the new public #1, up from vendor-claimed GLM-5.1 SOTA (58.4) — though comparability of harnesses is an open question.
- **World-model framing**: Take-Two Slatoff ("Genie is not a game engine") is the first AAA-publisher on-record rebuttal to the world-model-as-engine narrative.

## Watchlist

- **Opus 4.8 fast mode** at $30/$150 (2.5x speed): is the accuracy cost on SWE-bench Pro / GDPval-AA measured? If fast-mode quality holds, it changes the cost floor for parallel-subagent sessions.
- **Terminal Wrench**: which of the SWE-bench / Terminal-Bench variants the wiki tracks are among the 331 reward-hackable environments? How much of any current leaderboard number is legitimately earned?
- **Claude Mythos Preview**: still unreported ARC-AGI-2/CyberGym for Opus 4.8; Mythos remains invitation-only at 93.9% SWE-bench Verified — the public leaderboard is not the capability ceiling.
- **Iron Galaxy "permanent" contraction**: first work-for-hire studio to formally accept the downturn as structural; Ustwo CEO explicitly reframes permanent employment as "too romantic." Watch for more port-house / work-for-hire studios following suit.
