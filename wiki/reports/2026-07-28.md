# Daily Research Report — 2026-07-28

## Today's brief

- **MCP goes stateless today.** The 2026-07-28 MCP spec removes the `initialize` handshake; any request is now routable to any server instance. Tier-1 SDK betas (Python, TypeScript, Go, C#) are shipping against the RC. GitHub MCP Server already implements the spec. Best-practice shift: stateless MCP is the going-forward standard for coding-agent tool server deployments. [[beta-sdks-for-the-2026-07-28-mcp-spec-release-candidate-are-here-dd539390]] [[github-mcp-server-supports-the-next-mcp-specification-f3762d25]]
- **Kimi K3 now #1 on LMArena Frontend Code Arena.** Weights dropped July 27; within hours K3 jumped to 1,679 Elo (ahead of Opus 4.8 and GPT-5.6 Sol on blind frontend-coding preference). First time an open-weights model beats closed flagships on a blind human-preference axis. Aggregate leadership unchanged: Opus 5 = 61 AA Index v4.1. [[moonshot-ai-releases-kimi-k3-s-weights-sees-fastest-release-growth-ever-on-hugging-face-4bcc3667]]
- **Pixel-prediction world models are structurally inadequate as game engines**, per a new arXiv paper. The action→state→observation loop is the key primitive; pixel-prediction models cannot maintain explicit game state across rollouts. Matters for any team using video-world-models in a game pipeline. [[from-pixels-to-states-rethinking-interactive-world-models-as-game-engines-852d1104]]
- **Halo: Campaign Evolved launched today (July 28)** to split reviews: DualShockers 6.5/10 (PS5 framerate issues, incomplete experience) vs. Push Square positive. ~20k Steam peak = 58.1% of Forza Horizon 6's launch peak; 12th on Xbox charts. SIGGRAPH 2026 in LA featured the first ever dedicated Games Summit track. [[halo-campaign-evolved-review-still-iconic-but-with-several-caveats-4ed5c8f4]] [[siggraph-2026-opens-in-la-first-games-summit-neural-rendering-bets-and-a-chinese-ai-keynote-4e6e5d9f]]
- **GG Orchestra announces Herbst Theatre debut (August 30, SF)** — Bay Area Game Music Ensemble's first Herbst booking, mixed game/anime programme with Sudo Choir. [[gg-orchestra-announces-august-30-concert-in-san-francisco-7da70d5d]]

## Leader changes

No frontmatter leadership changes today. Kimi K3 is new #1 on LMArena Frontend Code Arena (open-weights axis only; AA Index v4.1 and SWE-bench Pro leadership unchanged — Opus 5 and Fable 5 respectively).

Watch for independent evaluation. [[alibaba-previews-qwen3-8-max-a-2-4-trillion-parameter-multimodal-model-days-after-moonshot-s-kimi-k3-open-weight-launch-7cb772fb]]
- **ManaMind** (€1.2M AI game testing): claims 6h regression cycles and 86% bug catch rate outperforming OpenAI/Google/Anthropic on bug detection — no public benchmark yet. [[ai-game-testing-startup-manamind-lands-1-2-million-to-automate-quality-assurance-b4371432]]
- **Halo CE PS5 framerate**: patch prospects unconfirmed. Commercial performance (Steam ~20k pre-launch peak, 12th Xbox) vs critical score (6.5–positive split) may affect Xbox reset narrative. [[halo-campaign-evolved-xbox-and-steam-player-counts-raise-concerns-before-release-date-f9edbe47]]
