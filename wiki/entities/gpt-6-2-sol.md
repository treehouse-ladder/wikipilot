# GPT-6.2 Sol

## Summary

GPT-6.2 Sol is OpenAI's efficient, versatile model released **2026-11-17** alongside GPT-6.2 Astra. It is available via the OpenAI API as `gpt-6.2-sol` with Ultrafast available at launch [[introducing-gpt-6-2-astra-and-sol-8f6af8c4]]. **GPT-6.2 Sol scores 57 on the AA Intelligence Index** (max), unchanged from GPT-6.1 Sol [[gpt-6-2-sol-intelligence-performance-price-analysis-c8b8562e]]. Effort-level scores: **57 (max), 56 (xhigh), 55 (high), 53 (medium), and 41 (low)** [[gpt-6-2-sol-intelligence-performance-price-analysis-c8b8562e]].

Pricing: **$2/$10 per Mtoken** (input/output), **unchanged from GPT-6.1 Sol** [[introducing-gpt-6-2-astra-and-sol-8f6af8c4]] [[gpt-6-2-sol-intelligence-performance-price-analysis-c8b8562e]].

On the **Coding Agent Index**, GPT-6.2 Sol **loses 3 points relative to GPT-6.1 Sol** [[openai-has-the-2-model-in-the-intelligence-index-with-the-release-of-gpt-6-2-astra-and-gpt-6-2-sol-c19f50a3]].

Safety: GPT-6.2 Sol falls below the "High" threshold for AI Self-Improvement capabilities but is classified as **"Critical" for cybersecurity** (like GPT-6.2 Astra) [[introducing-gpt-6-2-astra-and-sol-8f6af8c4]].

> GPT-6.2 Sol (max) scores 57 on the Artificial Analysis Intelligence Index. GPT-6.2 Sol was released on November 17, 2026. [[gpt-6-2-sol-intelligence-performance-price-analysis-c8b8562e]]

> GPT-6.2 Sol keeps GPT-6.1 Sol's API token prices of $2 per million input tokens and $10 per million output tokens. [[introducing-gpt-6-2-astra-and-sol-8f6af8c4]]

> GPT-6.2 Sol is priced at $2 per million input tokens and $10 per million output tokens, unchanged from GPT-6.1 Sol. [[gpt-6-2-sol-intelligence-performance-price-analysis-c8b8562e]]

> On the Artificial Analysis Coding Agent Index (Codex harness, max effort), GPT-6.2 Astra is flat with GPT-6 Astra, and GPT-6.2 Sol loses 3 points relative to GPT-6.1 Sol. [[openai-has-the-2-model-in-the-intelligence-index-with-the-release-of-gpt-6-2-astra-and-gpt-6-2-sol-c19f50a3]]

> GPT-6.2 Astra meets the High threshold for AI Self-Improvement capabilities, while GPT-6.2 Sol falls below it. Both models are treated as Critical for cybersecurity. [[introducing-gpt-6-2-astra-and-sol-8f6af8c4]]
