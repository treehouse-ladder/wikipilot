# Kling 4.0

## Summary

Kling 4.0 (cinematic quality) and Kling 4.0 Flash (speed/cost) are Kuaishou's latest video generation models, both available via the Kling API and Replicate, released October 15, 2026 [[kling-4-0-and-4-0-flash-video-generation-models-launch-b0391b87]]. The Kling API pricing page lists Kling 4.0 as "Coming Soon" with preview rates (720p 1.0 unit/s without video input, 1080p 1.5 units/s; with video input: 0.6/0.9 unit/s), which cannot yet be used for live requests [[kling-api-pricing-fba30089]].

> Kling 4.0 and Kling 4.0 Flash are the latest video generation models from Kuaishou. Kling 4.0 targets cinematic quality; Kling 4.0 Flash targets speed and cost. Both are available via the Kling API and replicate.com. Last release: October 15, 2026.

> The Kling API pricing page lists Kling 4.0 as Coming Soon. Kling 4.0 API access is not yet available, and the prices are for preview purposes only and cannot be used to submit requests before launch. Preview API rates per second of output: without video input, 720p is listed at 1.0 unit/s and 1080p at 1.5 units/s. With video input, the rates drop to 0.6 and 0.9 units/s.
