# Sora

## Summary

Sora is OpenAI's text-to-video model line, now discontinued. The Sora web and app experiences closed on April 26, 2026 and the Sora API (models `sora-2`, `sora-2-pro` and their dated snapshots) was discontinued on September 24, 2026 with no recommended replacement; API developers were notified on March 24, 2026 [[what-to-know-about-the-sora-discontinuation-4d8dc7c1]]. OpenAI has stated it has no plan or timeline for an open-weights or self-hostable Sora release, so there is no public access path remaining (`access: ["none"]`) [[what-to-know-about-the-sora-discontinuation-4d8dc7c1]].

> The Sora web and app experiences were discontinued on April 26, 2026. The Sora API will be discontinued on September 24, 2026. [[what-to-know-about-the-sora-discontinuation-4d8dc7c1]]

> An OpenAI support response said they haven't verified an open-weight or self-hosted Sora release and have no release plan or timeline. [[what-to-know-about-the-sora-discontinuation-4d8dc7c1]]
