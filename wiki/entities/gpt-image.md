# GPT Image 2.5

## Summary

GPT Image 2.5 ships as two variants: **Flare** (speed and cost priority) and **Sunburst** (quality priority), both available in the OpenAI API as `gpt-image-2.5-flare` and `gpt-image-2.5-sunburst` respectively [[gpt-image-2-5-flare-and-sunburst-released-by-openai-cf34266e]]. Both variants support editing, inpainting, and outpainting via the image edit endpoint in addition to generation.

> GPT Image 2.5 Flare and Sunburst are the latest image generation models from OpenAI, available in the API as gpt-image-2.5-flare and gpt-image-2.5-sunburst. Flare prioritizes speed and cost, Sunburst prioritizes quality. Both support editing, inpainting, and outpainting via the image edit endpoint.
