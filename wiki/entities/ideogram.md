# Ideogram 3.0

## Summary

Ideogram 3.0 is the latest image generation model from Ideogram, available via the commercial API at ideogram.ai and on fal.ai [[ideogram-3-0-launches-with-open-weights-model-and-commercial-license-1f773818]]. An open-weights version is available on Hugging Face under a research-only license (not cleared for commercial use). The commercial API pricing and commercial-use terms are not stated by any ingested source.

> Ideogram 3.0 is the latest version of Ideogram's image generation model. An open-weights version is available on Hugging Face under a research-only license. The commercial API remains available at ideogram.ai. Ideogram is also accessible via fal.ai.
