# Ideogram 3.0

## Summary

Ideogram 3.0 is the latest image generation model from Ideogram, available via the commercial API at ideogram.ai and on fal.ai [[ideogram-3-0-launches-with-open-weights-model-and-commercial-license-1f773818]]. An open-weights version is available on Hugging Face under the Ideogram Non-Commercial Model Agreement (commercial use not permitted); a self-serve commercial weights license is available for $300/10k images/month [[licensing-ideogram-bdab80bb]]. Outputs generated via the commercial API may be used for any purpose including commercial use (vendor FAQ) [[licensing-ideogram-bdab80bb]]. On fal.ai, the API charges $0.03 (turbo), $0.06 (balanced), or $0.09 (quality) per image [[ideogram-text-to-image-api-on-fal-7cd91f04]].

> Ideogram 3.0 is the latest version of Ideogram's image generation model. An open-weights version is available on Hugging Face under a research-only license. The commercial API remains available at ideogram.ai. Ideogram is also accessible via fal.ai.

> Ideogram's pricing FAQ says the company does not claim ownership of your generated images, and you're free to use them for any purpose, including commercial use. Open weights are a quantized version of the model published on Hugging Face under the Ideogram Non-Commercial Model Agreement. Under that license, commercial use isn't permitted. The self-serve commercial license covers smaller self-hosted commercial use. Its price is listed as $300 for 10,000 images per month. [[licensing-ideogram-bdab80bb]]

> The fal.ai listing for Ideogram V3 API charges $0.03 with TURBO, $0.06 with BALANCED, and $0.09 with QUALITY per request. [[ideogram-text-to-image-api-on-fal-7cd91f04]]
