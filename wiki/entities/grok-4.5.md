# Grok 4.5

## Summary

**Superseded 2026-08-12 by [[grok-4.6]]** as the SpaceXAI flagship. Grok 4.6 is a post-training upgrade on the same foundation that gains **+5 on the AA Intelligence Index v4.1.1 (54 → 61)** at unchanged $2/$6 pricing, moving xAI from aggregate #7-cluster into a tie with GPT-5.6 Sol for #3 [[grok-4-6-returns-spacexai-to-the-intelligence-frontier-and-leads-on-cost-efficiency-bdc6284a]].

Grok 4.5 is xAI/SpaceXAI's coding-and-agentic flagship, released July 8, 2026 — trained alongside Cursor on tens of thousands of NVIDIA GB300 GPUs [[introducing-grok-4-5-c5fe4e15]]. Artificial Analysis places **Grok 4.5 (high) at AA Intelligence Index 54** — a large jump from Grok 4.3's v4.1 score of 38 — sitting below the Opus 4.8 (56)/GPT-5.5 (55) cluster and below GPT-5.6 Sol (59) on the post-July-9 board [[grok-4-5-brings-spacexai-to-the-intelligence-frontier-20480383]]. **Grok 4.5 in Grok Build scores 76 on the AA Coding Agent Index at just $2.49 per task** — versus Fable 5 in Claude Code ($11.80) and GPT-5.5 in Codex ($5.07) [[grok-4-5-brings-spacexai-to-the-intelligence-frontier-20480383]]. Pricing: $2/$6 per Mtoken, configurable reasoning effort (low/medium/high). Vendor benchmarks: Terminal-Bench 2.1 83.3%, SWE-bench Pro 64.7%, DeepSWE 1.0 62.0% [[introducing-grok-4-5-c5fe4e15]].

> Grok 4.5 is SpaceXAI's smartest model built to excel at coding, agentic tasks, and knowledge work. It was trained alongside Cursor. [[introducing-grok-4-5-c5fe4e15]]

> Grok 4.5 in Grok Build cost $2.49 per task while Fable 5 in Claude Code cost $11.80 and GPT-5.5 in Codex $5.07. [[grok-4-5-brings-spacexai-to-the-intelligence-frontier-20480383]]
