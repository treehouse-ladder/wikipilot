# Hyper3D Rodin

## Summary

Rodin is Hyper3D's AI-to-3D product; the current generation, Rodin Gen-2.5, is positioned around *control* across the full pipeline — generation speed, geometry complexity, texture quality, local detail, part-level editing, topology and downstream optimization — for game, VFX, real-time, 3D-printing and enterprise workflows [[how-hyper3d-rodin-gen-2-5-is-bringing-production-level-control-to-ai-3d-generation-41af1fa2]]. Its "Smart Low-Poly" topology mode produces animation-ready meshes and supports high-to-low-poly baking with normal maps [[how-hyper3d-rodin-gen-2-5-is-bringing-production-level-control-to-ai-3d-generation-41af1fa2]].

> Rodin Gen-2.5 is designed to bring more control into the full AI-to-3D production pipeline, from generation speed and geometry complexity to texture quality, local detail, part-level editing, topology, and downstream optimization.

> Smart Low-Poly topology generation produces production-ready meshes with proper topology for animation and support for high-poly to low-poly baking with normal maps for real-time performance.

The hyper3d.ai pricing page (October 2026) shows tiered subscription plans and a free credits-based entry tier, confirming both a web app and a public API access path [[pricing-plans-for-ai-3d-generation-ceafc9f6]]. The Business tier ($120/mo or $96/mo billed annually) is described as adding full API access, implying lower tiers have limited or no API access [[pricing-plans-for-ai-3d-generation-ceafc9f6]].

> Free: $0/mo, direct credits at $1.5/credit; Creator: $30/mo ($24/mo annually); Business: $120/mo ($96/mo annually) — adds full API access; Enterprise: custom pricing. [[pricing-plans-for-ai-3d-generation-ceafc9f6]]

Commercial-use terms are not stated in the ingested pricing source; that gap is filed under Open questions.
